# Simple Interest Calculator

## Description

The Simple Interest Calculator is a basic calculator used to calculate simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal Amount
- R = Rate of Interest
- T = Time Period in years

## Example

Principal Amount = ₹10,000

Rate of Interest = 5%

Time = 2 years

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = ₹1,000

Total Amount = ₹11,000

## Features

- Easy to use
- Calculates simple interest
- Calculates total amount
- Suitable for basic financial calculations
